    Use it in Ableton Live

    1. Press Download .amxd.
    2. Drag the file onto an audio track in Live (Suite, or Standard with Max for Live).
    3. Every dial here is a Live parameter: automate it, map it, save it with your set.

    The browser preview uses Web Audio stand-ins for Max's objects, so the tone in Live will be close, not identical.
